## 三、附注(易误认事实)

1. **rag/fallback 两族互斥注册**(依 isVectorized);resolveChapterReference 两版同名永不共存——配置覆盖双态需同列两族。
2. 全部工具均**不触发子模型**(tools/ 无 llm-provider 导入);"分析类"只是取原文喂主模型。
3. 命名:书库统计工具为 `getReadingStats`(非 readingStats)。
4. getCurrentChapter 已并入 getSurroundingContext(全库无该工具名)。
5. 决策过程与待办细节见 `三模式-选项决策.md`;历史分析: `history-analysis/AI工具矩阵与双维度裁剪.md`。
