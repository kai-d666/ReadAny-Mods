# K-O 模式"放松"清单(工具之外的维度)

> 状态:active(拍板中,2026-08-28)
> 背景:K-O 定位=知识为主+少量基础工具(详见同目录 `K-O知识模式-工具选型.md`)。本表列工具集之外还可放松/需补的维度,供决策。
> 勾选方式:决策列填 ✓(执行)/ ✗(放弃)/ ~~(待定)。

## 一、Prompt 语义层(A)

| 编号 | 项目 | 现状(K-O) | 可放松为 | 理由 | 成本 | 决策 |
|------|------|-----------|----------|------|------|------|
| A1 | "不检索/不引用原著"硬约束 | prompt 强制零检索 | 改为"知识优先,不确定时用基础工具核实;引用仅标注工具返回的定位" | 工具引入后原约束会打架 | 纯 prompt 措辞 | |
| A2 | 注入当前章正文 | 完全不注入 | 注入 currentChapter 前 ~2000 字符(有则注) | "这章讲了什么"最痛场景,不再靠猜;原"知识+当前章全文"扩展方向 | ~500 token/请求 | |
| A3 | 注入目录 TOC | 不注入 | 注入全部章标题(约 100-300 token) | 目录是元数据;"第N章讲什么/哪章有XX"免工具直接答 | 小 | |
| A4 | 注入选中文本 | 不注入 | selectionText 有则注 | 选中提问是读者最自然的注意力锚 | 小 | |

## 二、管线层(B,部分依赖工具集非空)

| 编号 | 项目 | 现状 | 可放松为 | 理由 | 成本 | 决策 |
|------|------|------|----------|------|------|------|
| B1 | 记忆摘要 | 跳过压缩(同 lite)→ 跨轮无记忆 | K-O 走 `maybeCompressThreadMemory`(达阈值才调用) | K-O 是默认档,跨轮记忆重要;现为"无意识省" | 阈值前零成本 | |
| B2 | 技能注入 | enabledSkills 清空 | 允许注入 | 用户自定义技能是个性化核心 | 小 | |
| B3 | 问题路由 | detectQuestionCategory 跑但未用 | 启用 filterToolsForQuestion | 章节类请求提前收敛 | 工程必然 | |
| B4 | recursionLimit | 直连无递归 | 工具非空后走 agent 循环(复用 lite 16 上限) | 有工具就需循环 | 工程必然 | |

## 三、防护类(C,补漏而非放松)

| 编号 | 项目 | 现状 | 建议 | 说明 | 决策 |
|------|------|------|------|------|------|
| C1 | 防剧透 | **未接入(已确认漏洞)** | 以 Reading Position 为界,后文内容不答/提示会剧透 | 手上已有位置信息,可守;其余两模式已生效(prompt 级) | |

## 四、微调类(维持现状,不动)

回复语言/简洁约束、温度(0.7)、deepThinking 生效——均沿用。

## 五、决策后依赖链

- A1/A2/A3/C1 建议必做(工具引入后拧巴点);A4/B1/B2 选做;B3/B4 随工具集非空自动需要。
- 工具选型(表三勾选)与本表独立决策,但 A2 与"是否留检索工具"有分工:A2 管"当前章",检索工具管"全书找东西"。
