## 核心结论

二次开发的功能几乎不互通:桌面线的 core 能力(ECDICT 词典、翻译弹窗、欧路网页内嵌、自动发音)移动端从未 import(grep 确认 app-expo 无 ecdict);移动端线的 core 能力(侧边翻页开关、松手弹词、选区守卫)桌面从未接入。两端的查词/翻译各走各的路。

## 值得注意的点

1. foliate-js fork 只被移动端线改过 1 次(d1a109b 选区锚定守卫)—— 两端共享该包,所以"选区防漂移"实际两端都有,只是音量键翻页只在安卓有意义。
2. 章节翻译是唯一的 cross 接回:桌面线在 core 沉淀 chapter-translator,移动端线后来自己接上(ChapterTranslationSheet),ECDICT/弹窗未接。
3. 二次开发方向演进:先补桌面查词翻译,再全力做安卓阅读器体验。30 条里 16 条移动端、12 条桌面+core、1 条 core 独占、1 条工程配置(dc9d429 expo prebuild)。
